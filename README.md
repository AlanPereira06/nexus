# NEXUS

**Your day. Your focus. Your rules.**

NEXUS is a lightweight personal dashboard for organizing your day without turning productivity into another complicated system.

## MVP

- Daily task management with priorities and progress
- Focus timer with 25, 50 and 90 minute sessions
- Quick scratchpad with automatic local saving
- Persistent notes
- Daily inspiration
- Light/dark appearance
- Responsive mobile layout
- No account or backend required: data stays in the browser via localStorage

## Run locally

No build step is required. Open `index.html` or serve the folder with any static server.

## Deploy

The project is intentionally static so it can be deployed immediately with GitHub Pages, Vercel, Netlify or Cloudflare Pages.

Built as the first NEXUS MVP.
